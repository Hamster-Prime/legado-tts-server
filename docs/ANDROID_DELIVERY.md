# Android 客户端交付报告

客户端在 [android/](../android/)。构建、安装、联网与验收步骤见[使用说明](../android/README.md)。

## 交付范围

- 简体中文的 miuix Compose 界面，随系统切换配色。启动与手动刷新读取服务端目录，支持分组、搜索、试听、收藏；以服务商和音色 ID 的组合标识音色。
- 首次配置同时检查地址、鉴权与目录，通过后才保存。Keystore 生成不可导出的 AES 密钥；AES-GCM 加密访问密钥，把完整服务地址作为附加认证数据，密文和随机 IV 位于 App 私有的 no-backup 目录。请求只向指定地址直连，不跟随重定向。不带统计、崩溃上报或账号同步 SDK，不记录密钥和朗读正文。
- 朗读优先按标点分段且不拆 Unicode 代理对，保留右引号/括号归属；流式服务商与系统单段请求采用更大分段上限以减少跨请求边界，缓冲型服务商首段保持较短以降低首声等待。每段使用 2 MiB 字节预算接收 MP3，当前段首块到达后最多并发预取下一段；解码后的 PCM 原样送入同一个 AudioTrack，不裁剪停顿或齿音。App 播放中由 AudioTrack 调速，不重复请求已合成内容。
- 前台媒体服务、MediaSession、锁屏与通知控制；处理焦点丢失、来电引起的暂时失焦、耳机拔出、停止和网络异常。暂停或停止释放唤醒锁，解码与音频输出有进度超时。
- 注册标准 `TextToSpeechService`，使用 App 当前所选的联网音色，按系统回调缓冲上限分批返回 PCM。旧版系统阅读器可直接绑定；不暴露设置写入或密钥读取接口。因面向同机其他 App，有权使用该引擎的阅读器也能消耗该服务的配额。

## 服务契约与限制

详细请求、字段、错误类型和实测证据见[接口核对](API_AUDIT.md)。本次适配中有以下影响验收的差异：

- `API_KEYS_REQUIRED=1` 才强制认证；只设置 `API_KEYS` 不等于开启认证。无单独的密钥验证 API，公开目录也不能验密钥。客户端利用合成路由的鉴权顺序作无音频探测，仍受限流。
- 目录是服务端公开的聚合目录，不是云厂商所有音色或凭证可用性清单。受管理权限保护的私有音色不会越权显示。试听采用服务器固定短句。
- Edge、火山引擎、Fish Audio 支持请求内流式。腾讯、小米按段返回；预取能降低等待，不能保证任意网速、代理缓冲或上游限流下都无间隙。
- 系统引擎的语言随选定音色，未提供各方言独立语言包；云端合成不离线。系统语速与 App 倍速结合；Fish 的系统引擎请求用 PCM 采样率补偿语速，音高可能随之变化。客户端不发送系统请求的逐句 pitch。
